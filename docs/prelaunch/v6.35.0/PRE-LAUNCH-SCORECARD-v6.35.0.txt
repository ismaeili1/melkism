Status model
------------

PASS
WARNING

Interpretation
--------------

PASS:
Local engineering contract is satisfied.

WARNING:
The item intentionally belongs to a later real-production
operation or requires live infrastructure.

BLOCKED:
A required local engineering condition is not satisfied.

Release Candidate policy
------------------------

A BLOCKED gate prevents transition to the Release Candidate.

Warnings are recorded and carried forward into the deployment
acceptance checklist.

Production deployment
---------------------

Actual production availability is NOT declared by v6.35.0.

The production milestone begins only after infrastructure,
database, deployment, smoke testing and user acceptance phases
are completed.
