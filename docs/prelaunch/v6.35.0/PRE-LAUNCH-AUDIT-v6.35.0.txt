MELKISM v6.35.0
PRODUCTION ACCEPTANCE & PRE-LAUNCH AUDIT

============================================================
Purpose
============================================================

This phase is the final local acceptance gate before creation of
the Release Candidate.

It evaluates the existing MELKISM foundation across:

- application foundation
- security
- health/readiness
- internationalization
- accessibility
- SEO
- deployment readiness
- observability
- performance
- search
- production scripts
- database foundation
- automated testing
- production build

============================================================
What this phase does NOT do
============================================================

It does not:

- deploy MELKISM
- modify production infrastructure
- connect to cloud APIs
- connect to the production database
- execute a production migration
- write production data
- publish the application
- submit URLs to search engines
- activate external analytics
- expose secrets

============================================================
Pre-launch principle
============================================================

A PASS in this phase means that the local repository has passed
the defined pre-launch engineering gates.

It does NOT by itself mean that public production infrastructure
has already been provisioned.

Actual deployment acceptance is performed in later phases.

============================================================
Repository policy
============================================================

Branch:
main

GitHub:
unchanged

No reset.
No destructive checkout.
No force push.
No automatic repository synchronization.

============================================================
Database policy
============================================================

No migration.

No database write.

No production database probe.

Prisma validation and generation remain local validation gates.

============================================================
Security policy
============================================================

Secret values are never printed.

Environment values are never copied into documentation.

Existing security headers remain authoritative.

============================================================
Completion
============================================================

v6.35.0 is considered locally complete when:

1. Pre-launch audit passes without BLOCKED gates.
2. Pre-launch tests pass.
3. Full automated tests pass.
4. Production readiness passes.
5. Prisma validate passes.
6. Prisma generate passes.
7. TypeScript passes.
8. ESLint passes.
9. Production build passes.

Warnings may remain only where they represent intentionally
deferred production operations such as actual infrastructure,
runtime secrets, external analytics and live indexing.
