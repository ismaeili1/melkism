# MELKISM Development Rules

1. Do not modify MELKIST.
2. Do not import source files directly from MELKIST.
3. Do not share MELKIST database tables.
4. Keep future integration behind lib/integrations/melkist/.
5. Preserve four-language architecture.
6. Preserve RTL/LTR support.
7. Validate TypeScript before advancing phases.
8. Validate production build before closing a phase.
9. Prefer minimal, isolated changes.
10. Every phase requires a validation gate.
