# MELKISM v5.5 — USER EXPERIENCE PLATFORM

## Objective

v5.5 establishes a unified User Experience Platform for the MELKISM intelligence ecosystem.

## Experience surfaces

- Hero
- Search
- Recommendations
- Market Intelligence
- Architecture Intelligence
- Property Discovery
- Research
- News
- Data
- Footer

## Core principles

- Unified discovery
- Multi-language support
- RTL / LTR support
- Responsive layout
- Explainable navigation
- Preservation of existing intelligence modules
- Platform-level experience boundary

## API

GET:

`/api/experience?locale=<locale>`

Supported locales:

- fa
- en
- ar
- tr

## UI

- `/fa/experience`
- `/en/experience`
- `/ar/experience`
- `/tr/experience`

## Integration

The Experience Platform surfaces the existing:

- Search Intelligence
- Recommendation Platform
- Market Intelligence
- Architecture Intelligence

without replacing their underlying modules.
