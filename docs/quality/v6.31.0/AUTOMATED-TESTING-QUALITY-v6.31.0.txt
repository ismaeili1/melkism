Purpose
-------
Establish a dependency-free automated architecture and contract-test
layer around MELKISM.

Test engine
-----------

Commands
--------

npm run test:quality

------
node --test tests/quality/*.test.mjs

----------
Foundation
Security

Performance
Observability
API contracts
Project integrity
Cross-phase safety

API contract principle
----------------------
The tests validate architectural responsibility boundaries.

The Search API route is responsible for:
- authentication context
- permission enforcement
- rate limiting
- delegation

Search input validation is owned by:
lib/search/search.types.ts
parseSearchInput()

Therefore page-size and query-bound assertions are tested against
the parser contract rather than incorrectly requiring those
implementation details inside route.ts.
