Architecture:
API -> Service -> Repository -> Prisma -> PostgreSQL

content

intelligence

title

name

key

key

key

summary

Query:
q = required, 2..200 characters

page:
positive integer, default 1

pageSize:
positive integer, maximum 50

entities:
optional comma-separated domain selector

Authorization:
authenticated user
content:read

Rate limit:
60 requests per minute per authenticated user

Ranking:
deterministic application-level text score
then updatedAt / recorded timestamp

No external search engine.
No vector database.
No new dependency.

No schema modification.
