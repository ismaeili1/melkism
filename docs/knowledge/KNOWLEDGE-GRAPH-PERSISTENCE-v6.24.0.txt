MELKISM v6.24.0
KNOWLEDGE GRAPH PERSISTENCE

============================================================
PURPOSE
============================================================

Provide the canonical PostgreSQL + Prisma persistence layer
and protected backend API foundation for the MELKISM
Knowledge Graph.

============================================================
PRISMA FOUNDATION
============================================================

KnowledgeNode
KnowledgeRelation

KnowledgeNodeType
KnowledgeRelationType

  ->

  ->

KNOWLEDGE NODE
============================================================

Collection:

DELETE /api/v1/knowledge/nodes/[id]

============================================================
SERVICE / REPOSITORY CONTRACT
============================================================

graphService.listNodes
    ->
graphRepository.listNodes

graphService.getNode
    ->
graphRepository.findNodeById

graphService.createNode
    ->
graphRepository.createNode

graphService.updateNode
    ->
graphRepository.updateNode

graphService.deleteNode
    ->
graphRepository.deleteNode

graphService.listRelations
    ->
graphRepository.listRelations

graphService.getRelation
    ->
graphRepository.findRelationById

graphService.createRelation
    ->
graphRepository.createRelation

graphService.updateRelation
    ->
graphRepository.updateRelation

graphService.deleteRelation
    ->
graphRepository.deleteRelation
